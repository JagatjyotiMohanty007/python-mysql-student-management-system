# Python MySQL Student Management System

A simple CRUD (Create, Read, Update, Delete) application built using Python and MySQL.

## Features

- Add Student
- View Students
- Update Student
- Delete Student

## Technologies Used

- Python
- MySQL
- mysql-connector-python

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python src/main.py
```

## Database Setup

Run:

```sql
database/schema.sql
```
